api docs

base url is your worker origin.

POST /api/shorten

body: { url, duration?, oneTime? } — duration like 15m, 1h, 24h (default), 1w, or custom 36h. oneTime: true burns the link after the first view.

{
  "url": "https://example.com",
  "duration": "24h",
  "oneTime": true
}
{
  "code": "abc123",
  "shortUrl": "https://yourdomain.com/abc123",
  "expiresAt": "...",
  "oneTime": true
}

POST /api/upload

multipart/form-data, field image + optional duration (15m, 1h, 24h default, 1w, custom 36h) + optional oneTime (true/1). max 10mb: png jpeg gif webp svg avif bmp ico.

{
  "code": "a1b2c3d4.png",
  "shortUrl": "https://yourdomain.com/img/a1b2c3d4.png",
  "expiresAt": "..."
}

GET /:code

301 to target. 404 if unknown, 410 if expired. one-time links are deleted on first view (second view 404s, served with no-store).

GET /img/:code

serves the uploaded image. 404 if missing, 410 if expired (expired objects are deleted on access). one-time images are deleted after the first serve (no-store).
